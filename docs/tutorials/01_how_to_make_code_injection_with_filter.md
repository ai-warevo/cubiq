# Руководство: Создание ассемблерного скрипта инъекции кода с фильтром целей
**Контекст:** Как перехватить общую функцию игры, разделить инструкции для локального игрока и врагов, и избежать вылета (краша) процесса.

Когда вы находите инструкцию, которая наносит урон, она почти всегда является **общей** (Shared Code) — через нее игра просчитывает и вас, и ботов, и сетевых игроков. Если просто отключить эту инструкцию, бессмертными станут абсолютно все. Чтобы чит работал правильно, нужно написать «фильтр».

---

## Шаг 1. Поиск общей инструкции (Shared Code)
1. Найдите точный адрес нужного значения в памяти (например, Health/ХП).
2. Нажмите по адресу правой кнопкой мыши и выберите **Find out what writes to this address** (`F6`).
3. Совершите действие в игре (получите урон / выстрелите), чтобы инструкция сработала.
4. В появившемся окне отладчика вы увидите строку кода. Запомните, какой **регистр** находится в квадратных скобках (например, `[ebx+04]`). Этот регистр хранит указатель на структуру персонажа, который в данный момент обрабатывается игрой.

## Шаг 2. Расчет выравнивания адресов (Alignment)
Перед сравнением нужно убедиться, что ваш статический указатель игрока (Local Player Pointer) и регистр из функции урона используют **одну и ту же точку отсчета**.
1. Посмотрите смещение ХП в вашем статическом указателе (например, `0xEC`).
2. Посмотрите смещение ХП внутри функции урона (например, `0x04` в инструкции `sub [ebx+04], esi`).
3. Найдите разницу: `0xEC - 0x04 = 0xE8`. 
4. *Вывод:* Функция урона принимает адрес, который сдвинут вперед на `0xE8` байт относительно официального начала структуры игрока. Перед сравнением нам нужно будет прибавить этот сдвиг к нашему базовому адресу.

## Шаг 3. Расчет затираемых байт (Размер JMP)
1. Выделите инструкцию урона в окне отладчика и нажмите **Show disassembler**.
2. Посмотрите на размер вашей инструкции в байтах (байт-код слева).
3. **Правило:** Инструкция `jmp newmem`, которую Cheat Engine вставит для перехвата, занимает строго **5 байт**.
4. Если ваша инструкция меньше 5 байт (например, занимает 3 байта), Cheat Engine принудительно затрет следующую за ней строку кода, чтобы освободить место.
5. Запишите затертую строку (например, `mov eax, esi`). Её **обязательно** нужно будет вручную восстановить в блоке `originalcode` скрипта, иначе игра вылетит.

## Шаг 4. Сборка скрипта в Auto Assembler
1. В окне **Memory Viewer** выберите верхнее меню **Tools -> Auto Assemble** (`Ctrl + A`).
2. В пустом окне выберите **Template -> AOB Injection** -> нажмите **OK**. Cheat Engine создаст базовый каркас.
3. Модернизируйте блок `newmem:` по следующему универсальному шаблону:

```assembly
newmem:
  // 1. Быстро вычисляем сдвинутый адрес нашего игрока и кладем его в свободный регистр EAX
  // Формула: [Базовый_Указатель] + Вычисленная_Разница_Сдвига
  lea eax, [[ac_client.exe+17E0A8]+0E8]

  // 2. Сравниваем текущую цель игры (в EBX) с нашим выровненным адресом (в EAX)
  cmp ebx, eax
  
  // 3. Если адреса совпали (это МЫ) — прыгаем в originalcode, где урон вырезан (Бессмертие)
  je originalcode

  // 4. Если адреса РАЗНЫЕ (это враг) — принудительно обнуляем ХП по его смещению
  mov [ebx+04], 0

originalcode:
  // 5. Саму инструкцию урона "sub [ebx+04], esi" мы не пишем (она пропущена для игрока)
  
  // 6. ОБЯЗАТЕЛЬНО восстанавливаем те инструкции игры, которые затер наш 5-байтовый JMP
  mov eax, esi         
  
  // 7. Возвращаемся в игровой цикл
  jmp returnhere
```

## Шаг 5. Сохранение и проверка
1. В окне ассемблера нажмите **File -> Assign to current cheat table**.
2. Закройте окно кода, перейдите в главную таблицу Cheat Engine и активируйте скрипт галочкой.
3. Если игра продолжает работать, боты умирают с одного выстрела, а вы не получаете урон — фильтрация настроена идеально.
